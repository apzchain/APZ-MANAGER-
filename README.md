# APZ Manager

مدیر APZ یک اپلیکیشن متن‌باز اندروید برای فهرست‌کردن برنامه‌های نصب‌شده، جستجو و ممیزی اولیه مجوزها است.

## وضعیت این مرحله
این بسته **مرحله ۱ (هسته قابل ساخت)** است: ساختار Android Studio، رابط Compose، فهرست برنامه‌ها، جستجو و امتیازدهی شفاف مبتنی بر قواعد مجوزها پیاده‌سازی شده‌اند. قابلیت‌های بکاپ رمزنگاری‌شده، XAPK/split installer، پاکسازی SAF و اتصال Shizuku در مراحل بعدی اضافه می‌شوند؛ در این مرحله ادعای پشتیبانی عملی آن‌ها وجود ندارد.

## پیش‌نیازها
- Android Studio Koala یا جدیدتر
- JDK 17
- Android SDK Platform 35
- دستگاه Android 13 یا جدیدتر (minSdk=33)

## ساخت
در Android Studio پوشه پروژه را باز کنید و اجازه دهید Gradle Sync کامل شود. سپس از منوی Build گزینه Build APK(s) را انتخاب کنید.

از خط فرمان:
```bash
gradle wrapper --gradle-version 8.9
./gradlew assembleDebug
```
فایل خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

> برای اجرای دستور بالا، Gradle نصب‌شده یا فایل Wrapper تولیدشده لازم است. فایل wrapper JAR و اسکریپت‌های اجرایی باینری در این بسته گنجانده نشده‌اند؛ Android Studio می‌تواند پروژه را باز و Wrapper را ایجاد کند.

## حریم خصوصی و محدودیت‌های Android
- برنامه فقط اطلاعات برنامه‌هایی را می‌خواند که Android PackageManager در اختیارش می‌گذارد.
- Android 11+ فهرست بسته‌ها را فیلتر می‌کند. برای فهرست گسترده‌تر باید سیاست Google Play درباره `QUERY_ALL_PACKAGES` رعایت شود؛ این مجوز عمداً در نسخه پایه درخواست نشده است.
- حذف برنامه‌ها باید از مسیر تأیید سیستمی انجام شود.
- داده خصوصی برنامه‌های دیگر بدون Root/Shizuku و مجوزهای معتبر قابل پشتیبان‌گیری نیست.
- امتیاز ریسک این نسخه تحلیل قطعی امنیتی یا هوش مصنوعی نیست؛ صرفاً یک heuristic قابل توضیح بر اساس مجوزهای حساس است.
